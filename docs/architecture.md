# Архитектура проекта

## Общая схема

Проект имеет простую модульную структуру: логика решения уравнений отделена от пользовательского ввода и тестов.

```text
Пользователь (коэффициенты a, b, c)
               |
               v
          main.cpp
      ввод / вывод
               |
               v
     quadratic(a, b, c)
  quadratic.h + quadratic.cpp
               |
               v
        vector<double>
               |
               v
         вывод корней

 test_quadratic.cpp --- Google Test ---> quadratic(a, b, c)
```

## Компоненты

| Компонент | Назначение |
|---|---|
| `quadratic.h` | Объявляет публичную функцию `quadratic(double a, double b, double c)` и её возвращаемый тип. |
| `quadratic.cpp` | Содержит реализацию вычисления действительных корней. |
| `main.cpp` | Принимает коэффициенты из стандартного ввода, вызывает функцию и выводит результат. |
| `test_quadratic.cpp` | Содержит автоматизированные проверки поведения функции с использованием Google Test. |

Названия приведены по присланному коду и выводу тестов; проверьте совпадение с файлами в репозитории.

## Принципы разделения ответственности

1. **Логика расчёта:** функция `quadratic` не должна зависеть от порядка ручного ввода и вывода данных.
2. **Точка входа:** `main` служит интерфейсом консольного приложения.
3. **Тесты:** вызывают `quadratic` напрямую, без запуска интерактивного сценария.
4. **Результат:** `std::vector<double>` содержит 0, 1 или 2 действительных корня; случай бесконечного числа решений выделен в исключение `std::invalid_argument` (в соответствии с тестом `InfiniteSolutionsThrows`).

## Поток данных

1. Программа считывает `a`, `b`, `c`.
2. Вызывает `quadratic(a, b, c)`.
3. Функция классифицирует уравнение по значению `a` и, при необходимости, `b`.
4. Для квадратного уравнения вычисляет дискриминант и соответствующие корни.
5. Возвращает вектор; при `a=b=c=0` выбрасывает исключение.
6. `main` выводит корни или информацию об отсутствии / бесконечности решений. Обработка исключений в `main` должна быть предусмотрена отдельно.

## Зависимости

- Язык: C++.
- Стандартная библиотека: `vector`, `cmath`, `algorithm` (в тестах), `stdexcept` (для исключения).
- Тестовый фреймворк: Google Test.

## Ограничения

- Возвращаются только **действительные** корни: комплексные не поддерживаются.
- Вектор не кодирует бесконечное множество решений — используется исключение.
- При работе с `double` возможны ошибки округления и потери точности; особенно это важно для дискриминанта около нуля и коэффициентов сильно разного масштаба.
- Допустимый диапазон входных коэффициентов и поведение для `NaN` / бесконечностей в текущем учебном контракте не определены.
