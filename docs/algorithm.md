# Алгоритм решения уравнений

## Интерфейс

```cpp
std::vector<double> quadratic(double a, double b, double c);
```

Функция решает уравнение

\[
ax^2 + bx + c = 0.
\]

**Вход:** три коэффициента типа `double`.

**Выход:** вектор действительных корней типа `std::vector<double>`.

- `0` элементов — действительных корней нет;
- `1` элемент — один действительный корень;
- `2` элемента — два различных действительных корня;
- `std::invalid_argument` — бесконечно много решений (`a = b = c = 0`).

Порядок двух корней не фиксируется контрактом; тесты сортируют их с помощью `sortedRoots`.

## Случай 1. Квадратное уравнение (`a != 0`)

Вычисляется дискриминант:

\[
D = b^2 - 4ac.
\]

- При `D < 0` действительных корней нет.
- При `D = 0` один корень: `x = -b / (2a)`.
- При `D > 0` два корня:

\[
x_{1,2} = \frac{-b \pm \sqrt{D}}{2a}.
\]

В реализации с плавающей точкой близость дискриминанта к нулю может проверяться с допуском. Фиксированный абсолютный допуск удобен для учебных примеров, однако может ошибочно объединять очень маленькие разные корни. Для общего случая необходимо отдельно продумать масштабно-зависимый критерий и численную устойчивость.

## Случай 2. Линейное уравнение (`a == 0`, `b != 0`)

Уравнение сводится к `bx + c = 0`, поэтому единственный корень:

\[
x = -\frac{c}{b}.
\]

## Случай 3. Вырожденные уравнения (`a == 0`, `b == 0`)

- Если `c != 0`, равенство `c = 0` невозможно: решений нет.
- Если `c == 0`, равенство верно для любого `x`: решений бесконечно много. По контракту тестов этот случай приводит к `std::invalid_argument`.

## Примеры

| Коэффициенты `(a, b, c)` | Тип | Ожидаемый результат |
|---|---|---|
| `(1, -5, 6)` | Два действительных корня | `2`, `3` |
| `(1, -2, 1)` | Один корень | `1` |
| `(1, 0, 1)` | Нет действительных корней | Пустой вектор |
| `(0, 2, -4)` | Линейное уравнение | `2` |
| `(0, 0, 5)` | Несовместное уравнение | Пустой вектор |
| `(0, 0, 0)` | Бесконечно много решений | Исключение |

## Особый случай `-0.0`

В IEEE 754 ноль имеет знак. Если требуется именно `+0.0`, результат можно нормализовать перед добавлением в вектор:

```cpp
if (x == 0.0) {
    x = 0.0;
}
```

Это имеет значение для теста, проверяющего `std::signbit(x)`.
