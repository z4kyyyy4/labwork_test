Лабораторная работа №4 — Unit-тестирование
О проекте
Проект представляет собой программу на C++ для решения квадратных уравнений вида
\[
ax^2 + bx + c = 0
\]
Для проверки работы функции quadratic() написаны модульные тесты с использованием Google Test.
Возможности программы
Функция quadratic(double a, double b, double c) возвращает std::vector<double> с действительными корнями уравнения.
- При a != 0 решает квадратное уравнение по дискриминанту.
- При a == 0 и b != 0 решает линейное уравнение.
- Если действительных корней нет, возвращает пустой вектор.
- При a == 0, b == 0, c == 0 выбрасывает std::invalid_argument, так как решений бесконечно много.

Проверяемые случаи
Тесты охватывают основные варианты работы программы:
- два различных действительных корня;
- один действительный корень;
- отсутствие действительных корней;
- иррациональные и отрицательные корни;
- нулевой корень (в том числе проверку знака нуля);
- погрешности вычислений с числами типа double;
- линейное уравнение при a = 0;
- отсутствие решений линейного уравнения;
- исключение при бесконечном количестве решений.
  Результат тестирования: 12 модульных тестов успешно пройдены.
  Запуск программы и тестов
  Ниже приведён пример команд для среды, в которой заголовки и библиотеки Google Test уже доступны компилятору:
# Сборка основной программы
c++ -std=c++17 main.cpp quadratic.cpp -o quadratic_app

# Запуск основной программы
./quadratic_app

# Сборка тестов
c++ -std=c++17 test_quadratic.cpp quadratic.cpp -lgtest -lgtest_main -pthread -o quadratic_tests

# Запуск тестов
./quadratic_tests
Если проект собирается через CMake или Google Test расположен в нестандартном каталоге, команды сборки могут отличаться. Используйте конфигурацию сборки вашего проекта.

Пример ввода коэффициентов для уравнения x² - 5x + 6 = 0:
1 -5 6
Ожидаемые корни: 2 и 3 (порядок может отличаться).
